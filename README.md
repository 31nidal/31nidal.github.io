# Nidal Yahyaoui — AI & Robotics Portfolio

Personal engineering portfolio presenting my background, technical interests, and selected work in artificial intelligence, robotics, perception, and software development.

**Portfolio:** https://31nidal.github.io/

## Selected projects

- **ARC-AGI-3 — Latent World Model Agent:** a research prototype exploring learned dynamics and model-based planning.
- **Autonomous Mobile Robot:** a team robotics project integrating voice commands, camera perception, LiDAR mapping, and control.
- **MyCorpus3D:** an interactive learning platform for health students.

## Technologies

The website uses semantic HTML5, responsive CSS Grid and Flexbox, CSS animations, inline SVG illustrations, and a small vanilla JavaScript enhancement. Google Fonts provides Fraunces, Inter, and IBM Plex Mono, with local fallback fonts.

The site is static, with no build process, backend, package installation, or API keys. Its dark visual design adapts to desktop and mobile screens and respects reduced-motion preferences. Content remains visible when JavaScript is disabled.

## Local preview

From this directory, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Deployment

Publish this repository as **31nidal/31nidal.github.io** with public visibility. Keep `index.html` at the repository root. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, and folder **/ (root)**, then save.

GitHub Pages serves the portfolio at https://31nidal.github.io/ once deployment completes.

## Structure

- `index.html` — portfolio content, styles, scripts, and SVG illustrations.
- `.nojekyll` — serves the static files without Jekyll processing.
- `README.md` — project overview and deployment instructions.

The portfolio content is in French. Career details and project descriptions are maintained by Nidal Yahyaoui.
